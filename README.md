# Веб-приложение для проведения интерактивных опросов
Создание веб-сервиса, позволяющего организаторам создавать квизы и управлять игровым процессом, а участникам — подключаться к игровым комнатам по коду, отвечать на вопросы и видеть итоговый рейтинг.
# Архитектура и стек технологий.
# Backend: 
В качестве серверной платформы выбран стек Node.js и Express.js обеспечивающий обработку REST-запросов для авторизации и управления. За мгновенную синхронизацию состояния игры и ответов между пользователями был выбран Socket.io. Безопасность хранения данных реализованы связкой библиотеки хэширования bcryptjs и встроенной базой данных SQLite3.
# Frontend 
Клиентская часть построена на нативном стеке HTML + CSS + JavaScript. Отвечает за отрисовку пользовательских и организаторских экранов.
# Описание схемы БД
Таблица users
| Колонка | Тип | Описание |
|---------|-----|----------|
| id      | INTEGER | уникальный номер пользоватедя |
| username | TEXT | имя пользователя |
| password | TEXT | хэш пароля пользователя |
| role     | TEXT | роль пользователя | 

Таблица history 
| Колонка | Тип | Описание |
|---------|-----|----------|
|id  | INTEGER | уникальный номер записи |
| username | TEXT | имя пользователя |

Таблица quizzes 
| Колонка | Тип | Описание |
|---------|-----|----------|
| id | INTEGER | уникальный номер квиза |
|title | TEXT | название квиза |
| category | TEXT | категория квиза |

Таблица questions 
| Колонка | Тип | Описание |
|---------|-----|----------|
| id | INTEGER | уникальный номер вопроса |

|type | TEXT | тип ответа |
|text | TEXT | текст вопроса |
|image_url | TEXT | url-ссылка на изображение(опционально) |

# Обоснование выбора средств разработки
Для реализации функционала был выбран современный стек технологий:

1. Backend (Node.js & Express.js): Обеспечивают высокую производительность асинхронной обработки HTTP-запросов.
2. База данных (SQLite3): Встраиваемая реляционная БД, не требующая развертывания отдельного сервера, что делает проект лёгким, мобильным и удобным для быстрого тестирования MVP.
3. Безопасность (bcryptjs): Применяется для надежного хэширования паролей пользователей.
4. Реальное время (Socket.IO / WebSocket): Двустороннее событийно-ориентированное соединение необходимо для мгновенной синхронизации состояния между сервером и всеми клиентами.
5. Frontend (HTML5, CSS3 / Bootstrap 5, JavaScript ES6+): Нативный веб-стек в связке с Bootstrap 5 обеспечивает быструю отрисовку клиентского интерфейса
   
# Основные этапы разработки
1. Проектирование UI/UX и архитектуры:
проработка пользовательских сценариев и макетов интерфейса в Figma
2. Проектирование модели базы данных:
разработка таблиц users, quizzes, questions, history.
3. Разработка серверной части: 
Создание эндпоинтов авторизации и регистрации
Реализация API для создания квизов организаторов и получения истории.
4. Реализация логики игровых комнат и настройка генерации событий.
5. разработка клиентского интерфейса:
Обработка экранов авторизации, личного кабинета, конструктора вопросов.
Написание клиентского скрипта для управления состояниями и обработки ответов разных типов.
6. Тестирование проекта:
Проведение тестирования приложения на группе пользователей.
