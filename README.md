# Веб-приложение для проведения интерактивных опросов
Создание веб-сервиса, позволяющего организаторам создавать квизы и управлять игровым процессом, а участникам — подключаться к игровым комнатам по коду, отвечать на вопросы и видеть итоговый рейтинг.
# Архитектура и стек технологий.
# Backend: 
В качестве серверной платформы выбран стек Node.js и Express.js обеспечивающий обработку REST-запросов для авторизации и управления. За мгновенную синхронизацию состояния игры и ответов между пользователями был выыбран Socket.io. Безопасность хранения данных реализованы связкой библиотеки хэширования bcryptjs и встроенной баззой данных SQLite3.
# Frontend 
Клиентская часть построена на нативном стеке HTML + CSS + JavaScript. Отвечает за отрисовку пользовательских и организаторских экранов.
# Описание схемы БД
Таблица users
| Колонка | Тип | Описание |
| id      | INTEGER | уникальный номер пользоватея |
| username | TEXT | имя пользователя |
| password | TEXT | хэш пароля пользователя |
| role     | TEXT | роль пользователя | 

Таблица history 
| Колонка | Тип | Описание |
|id  | INTEGER | уникальный номер записи |
| username | TEXT | имя пользователя |
| quiz_title | TEXT | название квиза |
| score | INTEGER | счет пользователя в сыгранном квизе |
|date | TEXT | дата игры |

Таблица quizzes 
| Колонка | Тип | Описание |
| id | INTEGER | уникальный номер квиза |
|title | TEXT | название квиза |
| category | TEXT | категория квиза |
|time_limit | INTEGER | ограничение времени на вопрос |

Таблица questions 
| Колонка | Тип | Описание |
| id | INTEGER | уникальный номер вопроса |
|quiz_id | INTEGER | ссылка на id квиза из таблицы quizzes| 
|type | TEXT | тип ответа |
|text | TEXT | текст вопроса |
|image_url | TEXT | url-ссылка на изображение(опционально) |
| options | TEXT | варианты ответа в формате JSON-строки|
| correct answer |  TEXT | индекс правильного ответа |
